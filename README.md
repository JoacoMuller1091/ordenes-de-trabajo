# Órdenes de trabajo digitales · Climatización Punilla

Proyecto de portafolio con un cliente ficticio.

**Ver la app funcionando:** https://joacomuller1091.github.io/ordenes-de-trabajo/

## El problema
Climatización Punilla, una empresa de instalación y service de aires acondicionados de Villa Carlos Paz, completaba las órdenes de trabajo en papel. Las planillas se perdían, a veces no se entendía la letra y pasar todo a la computadora llevaba horas.

## La solución
Una app web que el técnico usa desde el celular:

1. **Nueva orden:** datos del cliente y del equipo, checklist del service, mediciones (presión, temperatura), fotos (con opción de borrarlas) y firma del cliente en la pantalla.
2. **Informe PDF:** la orden cerrada se convierte en un informe prolijo que se descarga en PDF y se manda por WhatsApp o mail.

## Tecnologías
HTML, CSS y JavaScript sin frameworks. La firma usa Canvas y las fotos se cargan con FileReader.

## Cómo verlo
Entrá al link de arriba o abrí `index.html` en el navegador.
